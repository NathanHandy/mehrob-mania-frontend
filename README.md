# Mehrob Mania Frontend

This is the actual website — everything we designed together in chat,
now packaged as a real deployable project.

## Deploy it (using Vercel — free)

1. Push these files to a **new GitHub repo**, same way you did for the
   backend (create repo `mehrob-mania-frontend` → drag/upload all these
   files, including the `src` folder → Commit)
2. Go to **vercel.com** → sign up (using GitHub makes this easier)
3. Click **New Project** → select the `mehrob-mania-frontend` repo
4. Vercel will auto-detect this as a Vite project — just click **Deploy**
5. Wait 1-2 minutes — Vercel will give you a live URL like
   `https://mehrob-mania-frontend.vercel.app`

That's it — the real, live website. Right now it still shows sample
data (same as the chat preview) since it isn't connected to the
backend yet — that's the next step.
